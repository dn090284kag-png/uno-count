# 🃏 UNO Score Tracker (Веб-версія для компанії)

Сучасний, швидкий та зручний веб-додаток для підрахунку балів у настільній грі **UNO**.
Більше ніяких громіздких Google Таблиць, дрібних клітинок на телефоні та ручних підрахунків у голові!

---

## ✨ Основні можливості

- **📱 Мобільна оптимізація:** Великі зручні кнопки для пальців, ідеально працює як на смартфоні, так і на ноутбуці або планшеті.
- **🃏 Інтерактивний калькулятор карт:**
  - Не треба рахувати в голові: просто натискайте карти, які залишились на руках (`0-9`, `+2`, `⇄`, `⊘`, `🌈 Дика`, `🌈+4`).
  - Додаток сам підрахує точну суму за офіційними правилами!
- **🎮 Два популярні режими гри:**
  1. **Штрафні бали (Пенальті)** — *найпопулярніший для друзів*:
     - Переможець роздачі скидає всі карти й отримує **0**.
     - 🔥 **Згорання очок (Рівно 500 ➔ 0)**: якщо гравець набрав **точно ліміт балів (за замовчуванням 500)**, його рахунок повністю обнуляється і стає **0**! Додаток автоматично розраховує та показує `Ліміт - Поточні бали`, щоб кожен гравець бачив, скільки йому залишилося набрати до повного згорання.
     - 🖤 **Закінчення чорною картою**: якщо переможець скинув останньою чорну карту (Дика або +4), він отримує бонусний мінус: **-50, -100, -150** тощо, що списується з його загального рахунку! У додатку є швидкі кнопки в один клік для вибору бонусу: `0`, `-50`, `-100`, `-150`, `➕ -50`.
     - Інші гравці записують суму своїх карт.
     - 🚀 **Перевищення ліміту (+200 або Фінал)**: якщо хтось набрав більше ніж ліміт (наприклад, 501+ при ліміті 500), з'являється інтерактивна плашка: ви можете **продовжити гру (ліміт збільшується на +200)** або завершити та підбити фінальні бали!
     - 🏁 **Дострокове завершення гри**: спеціальна кнопка у верхній панелі дозволяє в будь-який момент за бажанням компанії завершити партію та показати фінальний подіум.
     - Хто набере більше ліміту (і компанія вирішить не продовжувати) — програє, а **виграє той, у кого найменше балів!**
  2. **Класичні офіційні правила:**
     - Переможець роздачі забирає суму карт усіх своїх суперників.
     - Гра триває до 500 балів.
- **📊 Таблиця + Картки лідерборду:**
  - Візуальні картки з рангами (🥇 1-е місце, 🥈 2-е місце, 🥉 3-є місце), прогрес-баром до ліміту та відривом від лідера.
  - Повна таблиця всіх раундів (як у звичних таблицях, але з підсвіткою переможців та швидким редагуванням/скасуванням).
- **💾 Надійне автозбереження:**
  - Усі дані гри та історія автоматично зберігаються в пам'яті браузера (`localStorage`). Якщо випадково закрити вкладку або розрядиться телефон — нічого не пропаде.
- **📤 Експорт та результат для чату:**
  - **Кнопка "Скопіювати для чату"**: генерує гарне повідомлення з медалями для Telegram, Viber, Instagram або WhatsApp.
  - **Завантаження CSV**: можливість завантажити файл для відкриття в Excel або Google Таблицях.
- **🎉 Свято перемоги:** Анімація конфеті, кубок переможця та підсумковий рейтинг для нагородження!

## 🚀 Як користуватися прямо зараз

1. Просто відкрийте файл [`index.html`](file:///c:/Users/Artem%20Klymov/Desktop/%D0%9C%D0%BE%D0%B8%20%D1%84%D0%B0%D0%B9%D0%BB%D1%8B/UNO%20count/index.html) у будь-якому сучасному браузері (Google Chrome, Microsoft Edge, Safari, Firefox).
2. Виберіть режим гри та ліміт очок (за замовчуванням 500).
3. Додайте імена ваших друзів (можна вибрати індивідуальний колір).
4. Натисніть **"Почати гру"**!
5. Після кожної зіграної партії тисніть **"Записати результат раунду"**:
   - Оберіть, хто скинув усі карти (1 дотик).
   - Для інших гравців введіть бали або натисніть **"🃏 Калькулятор"**, щоб просто потикати по картах.

## 🌐 Як викласти в інтернет (щоб друзі заходили зі своїх телефонів)

Оскільки додаток повністю клієнтський (чистий HTML5 + CSS3 + JS) і не потребує сервера чи баз даних, ви можете викласти його **безкоштовно за 1 хвилину**:

### Варіант 1: GitHub Pages (Найпопулярніший)

1. Створіть безкоштовний репозиторій на [GitHub](https://github.com).
2. Завантажте туди всі файли з цієї папки (`index.html`, `style.css`, `app.js`, `manifest.json`, `icon.svg`, `sw.js`).
3. Перейдіть у **Settings** -> **Pages** -> виберіть гілку `main` -> збережіть.
4. Отримайте постійне посилання типу `https://ваш-нік.github.io/uno-count/` і надішліть його друзям!

### Варіант 2: Vercel / Netlify (В один клік)

1. Відкрийте [vercel.com](https://vercel.com) або [netlify.com](https://netlify.com).
2. Просто перетягніть цю папку мишкою у вікно браузера (Drag & Drop).
3. Отримайте миттєве красиве посилання для гри.

## 📱 Як встановити як додаток на телефон (PWA)

Додаток підтримує стандарт PWA і має Service Worker для **100% автономної роботи без інтернету**:

- **На Android (Chrome):** Відкрийте посилання, натисніть меню (три крапки) -> **"Встановити додаток"** або **"Додати на головний екран"**.
- **На iPhone (Safari):** Натисніть кнопку "Поділитися" (квадрат зі стрілкою вгору) -> **"На початковий екран"**.

На екрані з'явиться фірмова іконка UNO, а додаток відкриватиметься на весь екран як повноцінна мобільна програма!
